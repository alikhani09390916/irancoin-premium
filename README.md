# IRANCOIN Premium

Premium AI Fintech Landing, Subscription & Dashboard Preview.

## Pages

- **Landing** — `index.html` (hero, features, pricing preview, FAQ)
- **Pricing** — `pricing.html` (plans, calculator, payment integration)
- **Dashboard** — `dashboard.html` (portfolio, charts, AI core)
- **Admin** — `admin.html` (payment management, user management)

## Tech Stack

- Vanilla HTML/CSS/JavaScript (zero build step)
- Supabase (backend, auth, edge functions)
- Three.js (3D brain visualization)
- NOWPayments (crypto payment processing)
- GitHub Pages (hosting)

## Development

```bash
# Local development
python3 -m http.server 8000
# or
npx serve .
```

## Deployment

Auto-deploys to GitHub Pages on push to `main`.
